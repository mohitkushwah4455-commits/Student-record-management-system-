STUDENT MANAGING RECORD SYSTEM

Lightweight python program build to handle the database of the students efficiently.

having the feature of updating the student name
and roll number and displaying it on the screen

language used is : python 3.14

Method to run the code:-

1. Download the repository to your local machine.
2. Open your terminal or command prompt and navigate to the project directory.
3. Run the script using the following command:
   ```bash
   python student_management.py
   ```

PROJECT STURCTURE AND LOGIC

Data structure: it helps to maintain the student record by the dynamic library usage of dictionary!

modules that are included:-
1. add_student(): update the student name
2. search_student(): search the student name by roll number.
3. update_marks(): helps to update the marks of the students.
4. display_students(): display the record section of the student.
